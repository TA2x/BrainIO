# BrainIO — Arduino EEG Made Easy

## Overview

BrainIO is a beginner-friendly Arduino library designed to simplify working with EEG (Electroencephalography) signals.

Instead of dealing with complex signal processing and raw data interpretation, BrainIO provides a clean API to:
- Detect blinks
- Estimate focus levels
- Read EEG signals

Suitable for prototyping, education, and hackathons.

---

## Features

- Simple setup
- EEG abstraction layer
- Blink detection
- Focus level estimation (0–100)
- Real-time signal reading
- Clean API
